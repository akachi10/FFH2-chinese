# MagisterModmod 汉化 · 技术路线

目标:产出 `MM汉化MOD/`——与 MagisterModmod(2023-10-20)目录同构的**覆盖包**,玩家把包内文件整体复制进 `Mods/MagisterModmod/` 覆盖即完成汉化。一次交付全量汉化,不出中间版本。

## 已验证机制(证据来自 0.41o 官方汉化包逆向 + MM 源码盘点)

1. **文本形态**:Civ4 文本 XML 每条 `<TEXT>` 为 `<Tag>` + `<English>/<French>/<German>/<Italian>/<Spanish>`(MM 全部 111 文件、12,725 条统一此结构,部分条目含 `<Gender>/<Plural>` 变体)。
2. **官方汉化包做法**:保留英文列,新增 `<Chinese>` 列,中文以 XML 数字实体(`&#x6253;` 形式)存储——文件字节纯 ASCII,编码声明(GB2312/Big5)与实体无关。该做法**依赖简体中文版 BtS 的可执行程序**才认得 Chinese 列。
3. **字体**:中文显示靠 theme(`Civ4Theme_Common.thm` 字体节)指向系统字体 SimSun(宋体),官方包未携带任何 ttf;`GameFont*.tga` 是图标字模(宗教/魔力图标等),与中文字形无关。
4. **MM 文本载体分布**:99% 玩家可见文本走 TXT_KEY 查表(XML);例外仅 8 个 PrivateMaps 地图脚本的硬编码英文描述、模组 ini 的名称/描述 2 条、DLL 内嵌少量字符串。

## 关键决策(硬锚点,全 Sprint 不可违反)

| # | 决策 | 理由 |
|---|------|------|
| A1 | 中文写入 **`<English>` 列**,以**数字实体**(`&#x....;`)形式;**不用** `<Chinese>` 列 | 英文版 BtS(GOG/Steam)直接可用,免"中文版 BtS"前置;实体形式绕开一切文件编码坑(官方包已证明引擎解析实体无碍) |
| A2 | 目标语言**简体中文**;复用译文取自官方包 **gb2312 目录变体**(简体实体) | big5 变体是繁体 |
| A3 | **不覆盖 MM 的 `GameFont.tga` / `GameFont_75.tga`** | MM 自带的图标字模含 MM 新增图标,官方包的旧版会破坏 MM 图标;中文字形不靠它 |
| A4 | 字体只走 theme:覆盖包携带按 MM 的 theme 引用链适配的 `.thm`(字体指向 SimSun) | 官方包已验证的显示方案 |
| A5 | `TXT_KEY` 名、占位符(`%s1`/`%d1`)、标记(`[COLOR_*]`/`[ICON_*]`/`[NEWLINE]`/`[PARAGRAPH:*]`/`[LINK=*]`)、`<Gender>/<Plural>` 结构**原样保留** | 破坏即游戏内报错/串文 |
| A6 | 官方汉化包的 **python 一律不用**;地图脚本汉化直接改 MM 版本的 8 个 .py | MM 重写过 python,官方包 python 基于原版 FFH2,盖上必坏 |
| A7 | `MM源码/` 只读基准;一切产出只进 `MM汉化MOD/` | 目录契约 |
| A8 | 复用译文前**逐 key 比对英文原文**:MM 英文与原版 FFH2 一致才复用;MM 改过英文的进"待翻译"清单 | MM 大量改写原版文本,盲目复用=文不对题 |
| A9 | **保守优先(用户 2026-07-23 拍板)**:一切以"游戏不报错"为第一目标,不挑战高难度方案;非核心载体(python 地图脚本、ini)若存在报错风险,宁可保留英文并在交付说明中注明 | 用户明确要求稳定压倒完整 |

## 载体处理清单

| 载体 | 规模 | 处理 |
|------|------|------|
| `Assets/XML/Text/*.xml` | 111 文件 / 12,725 条 | 覆盖包同名文件,中文入 English 列(A1);其余语言列保留原样 |
| theme(`Resource/`) | 1-7 个 .thm | 按 MM 引用链适配后随包携带(A4) |
| `PrivateMaps/*.py` | 8 个硬编码描述 | 改 MM 版脚本(A6),中文用 unicode 转义写法,避免 py 源码编码问题 |
| 模组 ini | 2 条 | Description 汉化;Name 保持 ASCII(目录/存档兼容) |
| DLL 内嵌字符串 | 少量 | **无法覆盖翻译**(二进制)。影响限于个别错误消息/断言文本,接受为已知限制 |
| BtS 本体核心 UI(主菜单/设置等) | — | 属基础游戏而非 MM,覆盖包不触及;英文版 BtS 下保持英文,接受为已知限制 |

## 验证手段

- **静态校验(每批强制)**:校验工具比对覆盖包 vs `MM源码/` 基准——XML 可解析、key 集合与结构一致、占位符/标记逐条守恒、实体合法。全绿才算批次完成。
- **游戏内验收(用户侧)**:本机无法运行 Civ4,最终显示效果由用户在 CrossOver 环境安装后确认;安装文档含 SimSun 字体进 bottle 的步骤(CrossOver bottle 默认无宋体)。
