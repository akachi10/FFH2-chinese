## 安装顺序(Windows 或 Mac + CrossOver 同理)

1. **装 BtS 并升到 3.19**:GOG 完全版自带 3.19,免打补丁;光盘/旧数字版需手动打 3.19 官方补丁
2. **装 FFH2 0.41**:运行 FfH2041.exe,装到 `...\Beyond the Sword\Mods\Fall from Heaven 2`
3. **打 patch o**:运行 FfH2041o.exe(它只认默认 Mods 路径,别改安装位置)
4. **装 MagisterModmod**:运行 Magister_Modmod_October_20_2023_Setup.exe。它会基于干净的 FFH2 0.41o 生成 `Mods\MagisterModmod`(内含 lfgr 的 More Naval AI v2.9.2u,无需单独装 MNAI)
5. **先跑一次英文版**确认能进游戏(BtS → Advanced → Load a Mod → 选 Magister 项)
6. **覆盖汉化**:把本仓库 `MM汉化MOD/` 下的 `Assets/` 与 `Resource/` 整体复制进第 4 步安装器实际生成的 MM 文件夹(名字可能是 `MagisterModmod` 或 `Magister Modmod for FfH2`,以实际为准),覆盖同名文件
7. **中文字体**:汉化包已携带 theme 配置(字体指向 SimSun);Windows 本机自带宋体无需操作,**CrossOver bottle 必须**把 `simsun.ttc` 拷入 bottle 的 `C:\windows\Fonts\`(从自有 Windows 的 `C:\Windows\Fonts\` 取),否则中文显示为方块

## 已知限制(交付口径)

- DLL 内嵌少量字符串(个别错误提示)与 BtS 本体核心 UI(主菜单等)不在汉化范围
- 地图脚本(PrivateMaps 8 个 .py)的英文描述与模组 ini 保留英文——M7/M8 按锚点 A9 主动放弃(python/ini 内嵌中文有报错风险,收益仅为地图选择界面几行描述)
- MM 源文件自带笔误原样保留(明细见 `M10一致性清单.md` 第 11/14 项)

## Mac(Apple Silicon)注意

- 原生 Mac 版 Civ4 是 32 位且不能加载自定义 DLL,**不可用**;必须走 CrossOver(推荐)或 Parallels + Windows
- CrossOver 里装 GOG 版完全版 → 后续 2/3/4 步全在同一个 bottle 里执行
- 汉化工程本身在 macOS 原生环境做(改 XML 而已),只有游戏内验收需要上面的环境

## 汉化工程目录约定

- `MM源码/`:MM 2023-10-20 的原始文件(来自 Changes.zip 解包),**只读基准,不改动**
- `MM汉化MOD/`:与 MM 目录结构同构的覆盖包,只含被翻译过的文件;发布/使用方式 = 整目录复制覆盖
