## TDD 期望(按翻译工程适配)

- **M4 校验工具就是本工程的测试体系**:先造"坏样本"(丢占位符/改 key/坏实体)证明工具能红,再投入使用——对应红→绿。
- M3/M4 工具代码本身:小体量脚本,常规自验(样例输入输出断言)即可,豁免完整 TDD(理由:一次性工具,校验对象即最终产物)。
- M6 每一批翻译:交付前必须 M4 全绿,校验报告随批次留存。

## 验收方案

- 末轮浏览器 E2E **不适用**(产物是游戏 Mod,本机无 Civ4 运行环境)。替代口径,已向用户声明:**静态校验全绿 + code-review 通过 = 仓库侧收口;游戏内显示效果由用户在 CrossOver 安装后自验**,发现问题回报修复。
- 已知限制(向用户明示):DLL 内嵌少量字符串、BtS 本体核心 UI 不在汉化范围。
