# 产品文档变更日志

本文件记录 `docs/product/` 的重大产品契约变更。产品最终形态见 [产品定义](./product-definition.md)，功能契约见 [PRD](./PRD.md)，交互见 [UE 交互规格](./UE-spec.md)。

## 2026-07-15：补记核心规则静态证据差距

- F002、F004、F006 的产品目标保持不变：死亡立即停止、运输货物按规则计入容量、城市训练受完成后容量约束、玩家级食物可持续。
- 记录 `CvPlayer` 的食物储备与每回合修正未见玩家流读写，且每回合修正仅有初始化与只读暴露、未见非零写入来源；保存/重载行为与外部来源列为运行未知。
- 记录运输货物成本被累加到后续未使用变量；货物是否实际影响容量拒绝列为运行未知。
- 记录城市训练容量检查只比较现有占用、未加入候选单位成本；训练后边界行为列为运行未知。
- 记录近战在双方同轮掷骰后才检查死亡；防守方先致死时是否仍发生攻击方同轮反击列为运行未知。
- 记录 `getDisableResearch() > 0` 会让 `COMMERCE_FOOD` 商业收入随所有商业类型返回 `0`；该耦合是否符合产品意图列为运行未知。
- 记录 `m_bIsWorked` 未见地块流持久化与其他规则消费；地块标记、Worker 位置和玩家账本的保存/重载一致性列为运行未知。
- 以上均为静态事实与推断风险，静态证据不构成 Windows 游戏环境复现结论，也不构成额外产品承诺。

## 2026-07-15：校准证据路径与移动度量

- Python 证据路径统一使用 Git 跟踪目录的精确大小写 `Rampage/Assets/python/`。
- F004 使用 Civ4 `plotDistance` 描述基于回合起点的移动半径；该网格度量为 `max(dx, dy) + floor(min(dx, dy) / 2)`，边界近似八边形。

## 2026-07-15：建立 Rampage 产品知识基线

### 文档变更

- 建立产品定义，明确目标用户、价值主张、核心循环、产品边界和成功标准。
- 建立以 F001 至 F007 组织的 PRD，并为每项功能给出可测试的 Given / When / Then 标准。
- 建立 Civilization IV 原生客户端 UE 规格，覆盖游戏设置、主 HUD、单位面板、近战预览、远程目标模式、Worker 动作、财务顾问、文明百科和战斗日志。
- 建立事实、产品定义、未知三类证据口径。

### 产品决策

- 将 `Rampage/` 确定为产品契约的目标代码线；`Fall from Heaven 2`、`Streak`、`Streak 3` 只保留为谱系证据。
- 将仓库定义为覆盖包，而非独立游戏或自包含模组发行物。
- 把兼容的 Windows Beyond the Sword 与 Fall from Heaven 2 Patch o 基础安装列为强制外部依赖。
- 把战斗/远程、移动/容量、工人占格生产、玩家食物经济定义为核心闭环。
- 不默认承诺遗留场景、事件、法术或单位类别可用；必须同时满足引用完整性与 Windows 运行验收。
- 不创建 Web 路由、跨平台运行承诺、关系数据库或虚构的专用错误页面。

### 证据摘要

- `5b397cd`（2014-06-21）：仓库起点标注 “FFH2 Patch o. No modifications.”
- `0786ba6`（2014-10-15）：加入 `Streak`。
- `bc6bf41`（2014-10-18）：加入 `Streak 3`。
- `4c9a642`（2015-08-12）：加入 `Rampage`。
- `6414f0e` 至 `49d4af0`：Rampage 代码线依次演化生命/敏捷战斗、多次攻击、远程、基于回合起点的 `plotDistance` 移动半径、容量、工人与玩家食物机制。
- `Rampage/installpatch.bat` 只覆盖外部模组目录中的 XML、Python、Art、res 与 DLL。
- Rampage 的四个可选氏族为 Air、Earth、Fire、Water；Barbarian 不可选。
- 四个顶层目录各含 21 个哈希集合一致的场景存档，场景仍引用 Rampage 文明表之外的文明。

### 保留未知

- 预编译 DLL 与 C++ 源代码的一致性。
- 城市容量等值边界、`Work Tile` 完成态、远程动作全局定义与快捷键冲突的运行行为。
- 遗留场景、事件、法术和单位类别的安全可达集合。
