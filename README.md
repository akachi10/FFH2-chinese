# FFH2-chinese · Magister Modmod 简体中文汉化

给《文明 4：超越刀锋》的 **Fall from Heaven 2** 及其衍生模组 **Magister Modmod for FfH2** 做的简体中文汉化，附带一些自用的平衡性改造。

**本仓库以汉化为主线**。平衡性改造是作者按自己的口味调的，与汉化彼此独立，不想要可以只取汉化部分。

## 这是什么

| 内容 | 位置 | 说明 |
|---|---|---|
| **汉化覆盖包** | [`MM汉化MOD-YK/`](MM汉化MOD-YK/) | 主线产出。12,725 条译文 + SimSun 字体 theme + YK 排布字模 |
| 平衡性改造台账 | [`MM玩法改造/README.md`](MM玩法改造/README.md) | 23 项改造的动机、定位、字节数、回滚方式 |
| 汉化工具 | [`tools/mm-l10n/`](tools/mm-l10n/) | 6 列格式转换、底稿叠加 |
| 上游源码快照 | `MM源码/` | 英文原版，只作字节比对的对照基准，不是发行内容 |
| 工作文档 | [`docs/`](docs/) | 架构、运维、排查记录 |

实际生效的游戏文件在另一个仓库：**[FFH2-game-files](https://github.com/akachi10/FFH2-game-files)**，那边按「改造 N」编号留痕，可与本仓库台账互查。

## 汉化说明

适配 **英克（YK）官方简体中文版 Civ4/BtS**（日版 CyberFront 底子）。中文版 exe 用的是 6 列文本格式，与英文版不同：

```
<Tag> <English>原文</English> <L1/> <L2/> <L3/> <L4/> <Chinese>译文</Chinese>
```

安装、字模选择、地图脚本汉化、以及安装期必须做的 Python 编码修补，全部写在 **[`MM汉化MOD-YK/README.md`](MM汉化MOD-YK/README.md)**——装之前请先读那份。

### 已知限制

地图上的**城市横幅**（城名、在造项）显示为问号。这是引擎唯一「宽字符按当前语言号选代码页转窄再贴图」的渲染路径，只有语言槽 5（YK 中文槽）走 GBK 才出汉字，而 MM 的 MNAI DLL 读槽 5 会启动崩溃。属当前路线下无解的已接受限制，其余界面（HUD、百科、悬浮、城市画面）全部正常显示中文。

## 平衡性改造

作者自用，按个人口味调整，**与汉化无关，可以不装**。都是 XML / Python 层改动，只有一项动了 DLL。挑几个有代表性的：

- 各族**王宫强化**（城防、城内单位每回合祝福、免费专家）——目标是让首都不那么容易被打掉
- **地图尺寸**整体放大，极大档 168×108
- **史诗巢穴探索**改为按地点冷却，可重复探索
- **阿尔达（Arda）判定**加入祭祀等级与单位经验
- 三桅战舰 / 主力舰**恢复运兵能力**（MM 原版只能挂猎鹰）
- 移除**附庸边境压制**——唯一的 DLL 二进制补丁，6 字节

完整清单与每一项的动机、实现、回滚方式见 [`MM玩法改造/README.md`](MM玩法改造/README.md)。

> ⚠️ 姊妹仓库 FFH2-game-files 里的 `Assets/CvGameCoreDLL.dll` **是打过补丁的**（移除附庸边境压制，改动 6 字节）。原版存证与带字节校验的 `--revert` 还原脚本都在台账里，介意的话可以自行还原成原版。
