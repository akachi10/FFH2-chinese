# MM 汉化覆盖包静态校验工具（M4）

`validate.py` 是 MM 汉化工程的**测试体系**：每一批翻译交付前必须跑它全绿，否则批次不算完成。
纯 Python 3 标准库，无第三方依赖。

## 用法

```bash
python3 tools/mm-l10n/validate.py [覆盖包目录] [基准目录]
```

- 默认覆盖包目录：`MM汉化MOD/Assets/XML/Text/`
- 默认基准目录：`MM源码/Assets/XML/Text/`
- 退出码：**全绿（可含 WARN）0**；有 FAIL 非 0（= FAIL 文件数，封顶 100）——可直接用于 CI/批次门禁。**WARN 不影响退出码**。

无参数即用默认目录：

```bash
python3 tools/mm-l10n/validate.py
```

覆盖包目录为空（M3 回填尚未产出）时，输出友好提示并退出 0，不阻塞。

## 校验规则（逐文件，对应硬锚点 A1/A5；校验口径 **v2** · SM 2026-07-23 裁决）

| # | 规则 | 档位 | 说明 |
|---|------|------|------|
| 1 | **可解析** | FAIL | `xml.etree` 解析通过 |
| 2 | **key 集合一致** | FAIL | 覆盖包 `<Tag>` 的集合、条数、**顺序**与基准完全一致（不增/删/重排/重复）|
| 3 | **数值占位符守恒** | FAIL | 每条 English 的 `%s1`/`%d1`/`%s2`… 数值占位符多重集与基准一致，**大小写敏感**（`%d1`≠`%D1`）。多重集不一致（含大小写差异）= FAIL（运行时报错风险）|
| 4 | **方括号标记** | WARN / FAIL | **口径 v2（含 LINK 方向分档）**：① 纯排版标记（`[NEWLINE]`/`[TAB]`/`[PARAGRAPH:N]`/`[COLOR_*]`/`[COLOR_REVERT]`/`[BOLD]`/`[ICON_*]` 等）多重集差异 = **WARN**；② LINK 类（`[LINK=*]`/`[\LINK]`/`[/LINK]`）**按方向**：译文相对基准**缺失** LINK = **WARN**（LINK 剥离的正常产物，显示无损）；译文相对基准**多出** LINK = **FAIL**（防后续翻译批引入悬空链接目标）；③ 覆盖包出现**已知合法词表之外**且**基准原文也没有**的未知标记 = **FAIL** |
| 5 | **其他语言未触碰** | FAIL | French/German/Italian/Spanish/**Finnish** 列（含 `<Gender>`/`<Plural>` 子结构）解析后值与基准逐字一致 |
| 6 | **改动行纯 ASCII** | FAIL | 仅对**相对基准发生改动**（被翻译）的 English 内容要求纯 ASCII——中文必须写成 `&#x` 数字实体（锚点 A1）。判定在**原始字节层**（实体是 ASCII、合法；原始中文字节 >0x7F 才 FAIL）。未改动内容以"与基准一致"为准（检查项 5 覆盖），基准历史既有的非 ASCII（如 CP1252 `\x92`）不判错 |
| 7 | **实体合法** | FAIL | 所有 `&#x`/`&#` 数字实体可解码，解码后无控制字符（`\t\n\r` 除外）|

### 合法标记词表（检查项 4-FAIL 判据）

从**基准 MM源码 + 官方 0.41o 汉化包的 English 列**归纳，用模式匹配覆盖以下合法族：
`[NEWLINE]` `[TAB]` `[SPACE]` `[PARAGRAPH]`/`[PARAGRAPH:N]` `[COLOR_*]`（含 `[COLOR_REVERT]`）`[ICON_*]` `[LINK=*]` `[\LINK]`/`[/LINK]` `[BOLD]`/`[\BOLD]` `[H1]`/`[H2]`/`[\H1]`/`[\H2]` `[CT_*]`/`[OUR_*]`（含 `:N` 序号变体）`[NUM<n>:...]` `[s1]`/`[d1]`/`[f]` 等单占位替身。
凡覆盖包译文出现且**不命中任一合法族、又不在该条基准原文中**的标记 → 未知标记 → FAIL。

### 设计要点

- **占位符/标记比对基于 English 列内容**：汉化后 English 存中文，但占位符/标记仍是 ASCII，提取逻辑不受影响。
- **检查项 3 大小写敏感**（口径 v2）：`%d1` 与 `%D1` 视为不同 → 差异即 FAIL；占位符多重集缺失/多余亦 FAIL。
- **检查项 4**（口径 v2）：纯排版标记重排（`[TAB]`↔`[NEWLINE]` 等）仅 WARN；LINK 类**按方向**——缺失 LINK（剥离）= WARN、多出 LINK（悬空链接风险）= FAIL；引入未知标记 = FAIL。
- **检查项 6 在原始字节层判定 + 只查改动行**：中文实体（`&#x..;`）是 ASCII，合法；直接写入的原始中文字节才 FAIL。未改动行由检查项 5 保证与基准逐字一致，其历史非 ASCII 不判错。
- **Finnish 列**：派单清单未列出，但真实基准有 977 条 Finnish；一并纳入"其他语言未触碰"保护。

## 红测/绿测（红→绿证据，口径 v2）

驱动脚本与样本在会话 scratchpad：`run_redtests.py` + `redtest/`（每例 base/over + `full_output.txt`）、`realcopy_report.txt`（真实基准 111 文件自拷贝报告）、`live_report.txt`（当前覆盖包实战校验报告）。

- **绿测**：① 合法汉化样本（中文入 English 实体，其他列不动）；② 原文自拷贝；③ **真实基准 111 文件整目录自拷贝 → 111/111 全绿、0 WARN**。
- **WARN 测**：纯排版标记差异 `[NEWLINE]` → 退出 0 且报 WARN。
- **WARN 测（LINK 方向）**：译文缺失基准 LINK（剥离）→ 退出 0 且报 WARN。
- **红测（含 v2 新增）**：丢占位符、改 key 名、删条目、写入原始 UTF-8 中文字节、坏实体、篡改 French/Finnish 列、篡改 Gender 子结构、重排 key 顺序、不可解析 XML、未知标记 `[BOGUS_UNKNOWN_TAG]`(FAIL)、**占位符大小写变化 `%d1→%D1`(v2=FAIL)**、真删数值占位符 `%s1`(FAIL)、**译文多出基准没有的 LINK `[LINK=*]…[\LINK]`(v2=FAIL)**、改动的 English 写原始中文字节(纯 ASCII FAIL)。
- **边界子测**：含 `\x92` 的真实文件原样拷贝 → 绿；同文件 English 注入基准没有的原始字节 → 红；空覆盖包目录 → 退出 0 友好提示。
