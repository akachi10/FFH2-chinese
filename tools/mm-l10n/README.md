# MM 汉化覆盖包静态校验工具（M4）

`validate.py` 是 MM 汉化工程的**测试体系**：每一批翻译交付前必须跑它全绿，否则批次不算完成。
纯 Python 3 标准库，无第三方依赖。

## 用法

```bash
python3 tools/mm-l10n/validate.py [覆盖包目录] [基准目录]
```

- 默认覆盖包目录：`MM汉化MOD/Assets/XML/Text/`
- 默认基准目录：`MM源码/Assets/XML/Text/`
- 退出码：**全绿（可含 WARN）0**；有 FAIL 非 0（= FAIL 文件数，封顶 100）——可直接用于 CI/批次门禁。**WARN 不影响退出码**。

无参数即用默认目录：

```bash
python3 tools/mm-l10n/validate.py
```

覆盖包目录为空（M3 回填尚未产出）时，输出友好提示并退出 0，不阻塞。

## 校验规则（逐文件，对应硬锚点 A1/A5；含 SM 2026-07-23 基于实物证据的两处修订）

| # | 规则 | 档位 | 说明 |
|---|------|------|------|
| 1 | **可解析** | FAIL | `xml.etree` 解析通过 |
| 2 | **key 集合一致** | FAIL | 覆盖包 `<Tag>` 的集合、条数、**顺序**与基准完全一致（不增/删/重排/重复）|
| 3 | **数值占位符守恒** | FAIL | 每条 English 的 `%s1`/`%d1`/`%s2`… 数值占位符多重集与基准一致，**大小写不敏感**（`%d1`≡`%D1`）。多重集不一致 = FAIL（运行时报错风险）|
| 4 | **方括号标记** | WARN / FAIL | **分两档**：① 标记多重集与基准不一致 = **WARN**（官方汉化对图鉴长文的排版标记做过合理重排，游戏内多年验证无碍）；② 覆盖包译文出现**已知合法词表之外**且**基准原文也没有**的标记 = **FAIL** |
| 5 | **其他语言未触碰** | FAIL | French/German/Italian/Spanish/**Finnish** 列（含 `<Gender>`/`<Plural>` 子结构）解析后值与基准逐字一致 |
| 6 | **改动行纯 ASCII** | FAIL | 仅对**相对基准发生改动**（被翻译）的 English 内容要求纯 ASCII——中文必须写成 `&#x` 数字实体（锚点 A1）。判定在**原始字节层**（实体是 ASCII、合法；原始中文字节 >0x7F 才 FAIL）。未改动内容以"与基准一致"为准（检查项 5 覆盖），基准历史既有的非 ASCII（如 CP1252 `\x92`）不判错 |
| 7 | **实体合法** | FAIL | 所有 `&#x`/`&#` 数字实体可解码，解码后无控制字符（`\t\n\r` 除外）|

### 合法标记词表（检查项 4-FAIL 判据）

从**基准 MM源码 + 官方 0.41o 汉化包的 English 列**归纳，用模式匹配覆盖以下合法族：
`[NEWLINE]` `[TAB]` `[SPACE]` `[PARAGRAPH]`/`[PARAGRAPH:N]` `[COLOR_*]`（含 `[COLOR_REVERT]`）`[ICON_*]` `[LINK=*]` `[\LINK]`/`[/LINK]` `[BOLD]`/`[\BOLD]` `[H1]`/`[H2]`/`[\H1]`/`[\H2]` `[CT_*]`/`[OUR_*]`（含 `:N` 序号变体）`[NUM<n>:...]` `[s1]`/`[d1]`/`[f]` 等单占位替身。
凡覆盖包译文出现且**不命中任一合法族、又不在该条基准原文中**的标记 → 未知标记 → FAIL。

### 设计要点

- **占位符/标记比对基于 English 列内容**：汉化后 English 存中文，但占位符/标记仍是 ASCII，提取逻辑不受影响。
- **检查项 3 大小写不敏感**：`%d1` 与 `%D1` 视作同一（SM 修订，避免误伤等价写法）；但真正的占位符多重集缺失/多余仍 FAIL。
- **检查项 4 两档**（SM 修订）：排版标记重排（`[TAB]`↔`[NEWLINE]`、`[PARAGRAPH:1]`↔`[NEWLINE]` 等）是官方汉化长文的合理做法，仅 WARN；只有引入未知标记才 FAIL。
- **检查项 6 在原始字节层判定 + 只查改动行**（SM 修订）：中文实体（`&#x..;`）是 ASCII，合法；直接写入的原始中文字节才 FAIL。未改动行由检查项 5 保证与基准逐字一致，其历史非 ASCII 不判错。
- **Finnish 列**：派单清单未列出，但真实基准有 977 条 Finnish；一并纳入"其他语言未触碰"保护。

## 红测/绿测（红→绿证据）

红测驱动脚本与样本在会话 scratchpad：`run_redtests.py` + `redtest/`（含每例 base/over 与 `full_output.txt`）、`realcopy_report.txt`（真实基准 111 文件自拷贝报告）、`live_report.txt`（当前覆盖包实战校验报告）。

- **绿测（4 项）**：① 合法汉化样本（中文入 English 实体，其他列不动）；② 原文自拷贝；③ **真实基准 111 文件整目录自拷贝 → 111/111 全绿、0 WARN**；④ 占位符仅大小写变化 `%d1→%D1`。
- **WARN 测（1 项）**：丢已知标记 `[NEWLINE]` → 退出 0 且报 WARN（标记重排不判 FAIL）。
- **红测（12 项）**：丢占位符、改 key 名、删条目、写入原始 UTF-8 中文字节、坏实体（控制字符）、篡改 French 列、篡改 Finnish 列、篡改 Gender 子结构、重排 key 顺序、不可解析 XML、**未知标记 `[BOGUS_UNKNOWN_TAG]`（=FAIL）**、**真删数值占位符 `%s1`（=FAIL）**、改动的 English 写原始中文字节（=纯 ASCII FAIL）。

## 红测/绿测（红→绿证据）

红测驱动脚本与样本在会话 scratchpad：`run_redtests.py` + `redtest/`（含每例的 base/over 与 `full_output.txt`），另有 `realcopy_report.txt`（真实基准 111 文件自拷贝报告）。

- **绿测**：① 合法汉化样本（中文入 English 实体，其他列不动）→ 绿；② 原文自拷贝 → 绿；③ **真实基准 111 文件整目录自拷贝 → 111/111 全绿**。
- **红测（11 项，逐一证明能红）**：丢占位符、改 key 名、删条目、写入原始 UTF-8 中文字节、坏实体（控制字符）、篡改 French 列、篡改 Finnish 列、篡改 Gender 子结构、重排 key 顺序、不可解析 XML、丢标记 `[NEWLINE]`。
- **边界子测**：含 `\x92` 的真实文件原样拷贝 → 绿；同文件 English 注入基准没有的原始字节 → 红；空覆盖包目录 → 退出 0 友好提示。
